# Checklist de publicación y reevaluación final

## Antes del push

- [ ] `npm run validate` aprobado.
- [ ] Edge, Chrome y Firefox revisados.
- [ ] Safari o iPhone revisado.
- [ ] Android revisado.
- [ ] Portafolio y privacidad accesibles.
- [ ] No existen carpetas nuevas `proyectos/` o `servicios/`.
- [ ] Commit de cierre creado.

## Publicación

- [ ] Push a `main`.
- [ ] Vercel desplegado sin errores.
- [ ] `www.ismdeveloper.cl` muestra la versión nueva.
- [ ] HTTPS y encabezados de seguridad verificados.
- [ ] Open Graph, sitemap y robots accesibles.

## Después de publicar

- [ ] Lighthouse móvil y escritorio.
- [ ] Formulario y WhatsApp probados en producción.
- [ ] Consentimiento de Analytics probado en ventana privada.
- [ ] Reevaluación integral y nota final.
