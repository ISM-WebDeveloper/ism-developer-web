Caso de estudio · Sistema web interno

ISM Gestión Control

Sistema web interno para centralizar inventario, recepciones, entregas, alertas, herramientas e historial operativo con acceso diferenciado por roles.

Contexto

Proyecto interno creado para probar y consolidar un sistema web reutilizable de inventario y operación para proyectos, bodegas e instalaciones.

Problema

Los movimientos de insumos y herramientas, recepciones, entregas, alertas y validaciones necesitaban una fuente central con trazabilidad y permisos diferenciados.

Solución desarrollada

Aplicación web con autenticación, selección de proyecto, módulos operativos y paneles separados para trabajadores, supervisores y administradores.

Funcionalidades

  • Inventario global y por proyecto.
  • Recepciones, entregas y movimientos.
  • Alertas y validaciones.
  • Herramientas, préstamos y mantenciones.
  • Historial, bitácora e importación desde Excel.
  • Empresas, proyectos, bodegas y usuarios.

Tecnologías

  • React
  • TypeScript
  • Vite
  • Supabase
  • PostgreSQL
  • Tailwind CSS
  • XLSX

Resultado verificable

El repositorio contiene rutas protegidas y módulos para tres perfiles, junto con servicios de inventario, alertas, recepciones, entregas, usuarios y reportes.

Estado y acceso

Piloto interno en desarrollo. No se publica un acceso con credenciales; la demostración está sujeta a autorización.
