# ISM Developer Web

Sitio oficial y portafolio interactivo de ISM Developer.

## Estructura

```text
assets/
  css/       Estilos del sitio y del portafolio
  img/       Imágenes, logotipos e iconos
  js/        Lógica del sitio y del dashboard
  vendor/    Librerías locales de terceros
index.html
portafolio.html
manifest.webmanifest
robots.txt
sitemap.xml
```

## Desarrollo local

```powershell
npm run dev
```

El servidor queda disponible en `http://127.0.0.1:4173`.

## Verificación

```powershell
npm run check
```
